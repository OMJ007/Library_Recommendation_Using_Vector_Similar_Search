# Library Recommendation System

An end-to-end book recommendation project implementing content-based filtering and collaborative filtering using vectorization techniques.

## 📁 Project Structure

- `Combining_Dataset.ipynb` - Data preprocessing, cleaning, and dataset consolidation.
- `Vectorization_and_Collabrative_Filtering.ipynb` - Text vectorization (TF-IDF / embeddings) and collaborative filtering model implementations.
- `*.csv` - Dataset files (books metadata, user interactions, ratings).

## 🚀 Getting Started

### Prerequisites

- Python 3.9+
- Jupyter Notebook / JupyterLab
- Required libraries: `pandas`, `numpy`, `scikit-learn`, etc.

### Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```

2. (Optional) Create and activate a virtual environment:
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. Launch Jupyter:
   ```bash
   jupyter notebook
   ```
